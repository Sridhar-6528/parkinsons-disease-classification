# 🧠 Parkinson's Multimodal AI Diagnostic System

> **3D Swin Transformer + Bidirectional Cross-Attention + DER++ Continual Learning**

Multimodal Artificial Intelligence Diagnostic Platform for Early Detection of Parkinson's Disease using Structural MRI & DaTscan SPECT Scans.

---

## 🚀 Quick Start

### 1. Install Dependencies
```bash
pip install -r requirements.txt
```

### 2. Launch Web Application
```bash
python web_app.py
```
Open **`http://127.0.0.1:5000`** in your browser.
